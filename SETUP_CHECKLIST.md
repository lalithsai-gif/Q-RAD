# Q-RAD launch checklist

- Windows Python is available (`py` or `python`).
- Node.js and npm are available.
- Run `RUN_WINDOWS.bat`.
- Wait for the API and Vite windows to start.
- Open `http://127.0.0.1:5173`.
- Upload a test image.
- Click `Analyze X-ray`.
- Check Overview, Findings, Quantum, Explainability, and How it works.
- Use Export to save the report JSON.
- Use Print to generate a browser print view.
